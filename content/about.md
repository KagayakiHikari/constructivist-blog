## 关于

这是一个部署在 **GitHub Pages** 上的静态个人博客。

它保留了构成主义视觉语言：红、黑、黄、蓝，粗边框，硬阴影，几何块面，以及海报式的页面结构。

## 工作方式

- 文章源文件位于 `content/posts`
- 页面样式位于 `static/styles.css`
- 构建脚本位于 `scripts/build-static.mjs`
- GitHub Actions 负责自动构建与部署

## 特点

- 无数据库
- 无后台
- 无服务端 API
- 纯静态 HTML
- 响应式布局
- 内容通过 Git 管理
