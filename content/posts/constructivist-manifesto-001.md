# 构成主义视觉宣言 001

构成主义不是装饰风格，而是一种**结构表达**。它相信秩序、冲突和几何张力可以直接传递思想。

## 视觉原则

- 红色负责能量与主张
- 黑色负责边界与重量
- 黄色负责警示与强调
- 蓝色负责理性与连接
- 网格负责秩序
- 斜线负责运动

> 网页不是纸，但它仍然可以拥有海报的力量。

## 设计语法

| 元素 | 处理方式 |
| --- | --- |
| 边框 | 粗黑硬边 |
| 阴影 | 偏移硬阴影 |
| 按钮 | 机械按钮 |
| 卡片 | 编号与块面 |
| 排版 | 强对比、强层级 |
